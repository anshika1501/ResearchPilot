# ResearchPilot AI — Frontend

This directory is reserved for the React frontend application (scheduled for Stage 2, Task D).

- Built with React and TypeScript.
- Communicates with the FastAPI backend through the `/api/v1` REST API.
- Modules for:
  - Document upload and ingestion monitoring.
  - Evidence-grounded chat with citation references.
  - Controlled research task orchestration and report viewer.
